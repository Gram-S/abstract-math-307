### Theorem 5.28 (Distribution of Union and Intersection)

<i>Let $A$, $B$, and $C$ be sets. Then prove the following.</i>

<i>(a) $A \cup (B \cap C) = (A \cup B) \cap (A \cup C).$</i>

*Proof.*

Denote $S = A \cup (B \cap C)$ and $T = (A \cup B) \cap (A \cup C)$.

<!-- Give T subsets? Like t_1 = A u B, t_2 = A u C -->

We know we can split $S$ into two sets, $A$ and $B \cap C$. Now consider the following about $T$. Since each union in $T$ contains $A$, the intersect of those unions contains all elements in $A$. Since each union in $T$ contains either $B$ or $C$ respectively, the intersect of those unions contains all elements in both $B$ and $C$. Thus, we can split $T$ into two sets, $\{ x : x \in A\}$ and $\{ y : y \in B \cap C\}$. But those sets contain the precisely the same elements as the partition of $S$. So, the union of those sets gives us both $S$ and $T$. Thus, $S$ and $T$ contain precisely the same elements. Therefore, by Proposition **5.20**, then $S = T$.

$\blacksquare$

<i>(b) $A \cap (B \cup C) = (A \cap B) \cup (A \cap C)$.</i>

### Theorem 5.31

<i>Let $S$ and $T$ be sets. Then $S \subseteq T$ if and only if $\mathcal{P}(S) \subseteq \mathcal{P}(T)$.</i>

*Proof.*

$\implies$ Assume $S \subseteq T$. Let there be an arbitrary element $a \in \mathcal{P}(S)$. Definition **5.29** tells us $a \subseteq S$. Then the **Transitivity of subsets** implies $a \subseteq T$. Since $a$ is arbitrary, every element in $\mathcal{P}(S)$ is a subset of $T$. Then, every element in $\mathcal{P}(S)$ is also an element in $\mathcal{P}(T)$. Therefore, $\mathcal{P}(S) \subseteq \mathcal{P}(T)$. 

$\impliedby$ Assume $\mathcal{P}(S) \subseteq \mathcal{P}(T)$. We know that $\mathcal{P}(S)$ contains $S$. Our original assumption tells us any element in $\mathcal{P}(S)$ is also in $\mathcal{P}(T)$. Thus, $S \in \mathcal{P}(T)$. Therefore, $S \subseteq T$.

Since we have proved both implications, we conclude $S \subseteq T$ if and only if $\mathcal{P}(S) \subseteq \mathcal{P}(T)$. 

$\blacksquare$
