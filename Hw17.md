### Theorem 4.22

*Proof.*

We use proof by contradiction. Thus, assume that there exists an integer $z$ such that for all natural numbers, $n$, then $4z \not= 1 + (-1)^n(2n-1)$. Consider the case where $n = 2z$. Now $(-1)^{2z} = 1$, because $2z$ is even. Then $4z \not= 1 + 2n - 1 = 2n = 4z $, which is a contradiction. Thus assuming there exists an integer $z$ such that for all natural numbers, $n$, then $4z \not= 1 + (-1)^n(2n-1)$, leads to a contradiction. Therefore, for all integers $z$, then there exists a natural number, $n$, such that $4z = 1 + (-1)^n(2n-1)$.

$\blacksquare$

### Theorem 4.23

*Proof.* 

We use proof by contradiction. Thus, assume that $\exists n : 3n^2 + n + 14$ is odd. There are two cases, where $n$ is even or not. 

If $n$ is even, then, $n = 2k$ for some integer $k$. Thus, $3n^2 + n + 14$

$$
= 3(2k)^2 + 2k + 14
= 12k^2 + 2k + 14
= 2(6k^2 + k + 7). 
$$

Now, we know the term $2(6k^2 + k + 7)$ is even, which contradictions our original assumption.

If $n$ is odd, then $n = 2k + 1$ for some integer $k$. Thus, $3n^2 + n + 14$

$$
= 3(2k + 1)^2 + 2k + 15
= 12k^2 + 14k + 18
= 2(6k^2 + 7k + 9).
$$

Now, we know the term $2(6k^2 + 7k + 9)$ is even, which contradicts our original assumption. 

So, assuming that $\exists n : 3n^2 + n + 14$ is odd always leads to a contradiction. Therefore, $\forall n : 3n^2 + n + 14$ is even.

$\blacksquare$
