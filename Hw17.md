### Theorem 4.22

For all $z \in \mathbb{Z}$, there exists $n \in \mathbb{N}$ such that $4z = 1 + (-1)^n(2n-1)$.

*Proof.*

We use proof by contradiction. Thus, assume that there exists an integer $z$ such that for all natural numbers, $n$, then $4z \not= 1 + (-1)^n(2n-1)$. We know there are two cases for $(-1)^n$ depending on if $n$ is even or odd. Now, $4z$ cannot be equal to both $-2(n - 1)$ and $2n$.

If $n$ is even. Then we let $n = 2z$ because **Def 2.1**, implies $2z$ is even. Thus, $2n = 4z$, which is a contradiction. 

If $n$ is odd. Then using **Def 2.2**, let $n = -2z + 1$. Thus, $-2(-2z + 1 - 1) = 4z$, which is a contradiction.

Therefore, $4z$ is equal to both $-2(n - 1)$ and $2n$. So the statement is not true $\forall z$. Therefore, there cannot exist $z$, so our original statement is false. So, $\forall z \in \Z$, then $\exists n \in \N : 4z = 1 + (-1)^n(2n -1)$.

$\blacksquare$

### Theorem 4.23

For all integers $n$, $3n^2 + n + 14$ is even.

*Proof.* 

We use proof by contradiction. Thus, assume that $\exists n : 3n^2 + n + 14$ is odd. There are two cases, where $n$ is even or not. 

If $n$ is even, then, $n = 2k$ for some integer $k$. Thus, $3n^2 + n + 14$

$$
= 3(2k)^2 + 2k + 14 \\
= 12k^2 + 2k + 14 \\
= 2(6k^2 + k + 7). 
$$

Now, we know the term $2(6k^2 + k + 7)$ is even, which contradictions our original assumption.

If $n$ is odd, then $n = 2k + 1$ for some integer $k$. Thus, $3n^2 + n + 14$

$$
= 3(2k + 1)^2 + 2k + 15 \\
= 12k^2 + 14k + 18 \\
= 2(6k^2 + 7k + 9).
$$

Now, we know the term $2(6k^2 + 7k + 9)$ is even, which contradicts our original assumption. 

So, assuming that $\exists n : 3n^2 + n + 14$ is odd always leads to a contradiction. Therefore, $\forall n : 3n^2 + n + 14$ is even.

$\blacksquare$
