**Exercise 5.7.** *Which of the sets $B, C, D$ from Exercise 5.4 are subsets of which others? Please prove your answer.*

*Claim:* For sets $B, C, D$, then $C, D \subseteq B$.

*Proof.*

Observe $B$ is the set of all real numbers in the range $-\sqrt{2}$ to $\sqrt{2}$  (inclusive). This range includes -1, 0, and 1. Thus, $C$ is a subset of $B$. Recall that $-\sqrt{2}$ to $\sqrt{2}$ includes the range 0 to 1. Subsequently, we know that $\frac{1}{n}$ for $n \in \mathbb{N}$ can only express numbers in the range 0 to 1. Thus, subtracting it from 1 will also produce number in that range. Thus, $D$ is a subset of $B$. Therefore, for sets $B, C, D$, then $C, D \subseteq B$. 

$\blacksquare$

**Theorem 5.8.** *Let $S$ be a set. Then $S \subseteq S$ and $\emptyset \subseteq S$.*

*Proof.*

Let $S$ be an arbitrary set. By **Def 5.6**, we can show that a set $S'$ is a subset of $S$ by using the following the method to build $S'$. Let $S'$ originally be the $\emptyset$. Then add to $S'$, some elements also in $S$. Now, we can build $S'$ in the following ways.

Add no elements of $S$ into $S'$. Now $S' = \emptyset$. Thus, $\emptyset \subseteq S$. 

Add all elements of $S$ into $S'$. Now $S' = S$. Thus, $S \subseteq S$.

Therefore, if $S$ is a set, then $S \subseteq S$ and $\emptyset \subseteq S$.

$\blacksquare$
