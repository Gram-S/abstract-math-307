*Proof.*

<i>Let $A$ and $B$ be the sets in the same universe $U$. Then $(A \setminus B) \cup (B \setminus A) = (A \cup B) \setminus (A \cap B)$</i>.

Assume $A$ and $B$ are sets. Now, without the loss of generality, there are two cases depending if $A = \emptyset$ or $A = B$.

Assume $A = \emptyset$. Then we know the following.

$\emptyset \setminus B = \emptyset$

$B \setminus \emptyset = B$

$\emptyset \cup B = B$

$\emptyset \cap B = \emptyset$.

Now, we know $\emptyset \cup B \subseteq B \setminus \emptyset$ and $B \setminus \emptyset \subseteq \emptyset \cup B$. So, Definition **5.19**, imples our original statemnet holds when $A = \emptyset$.

Assume $A = B$. Then we know the following.

$A \setminus B = \emptyset$

$B \setminus A = \emptyset$

$A \cup B = B$

$A \cap B = B$

Now we know $\emptyset \subseteq B \setminus B$ and  $B \setminus B \subseteq \emptyset$. Thus our original statement holds when $A = B$.

Assume $A, B \not= \emptyset$ and $A \not= B$. Then we know there is at least 1 element in $A \setminus B$ and $B \setminus A$. So let there be $x \in A : x \in A \setminus B$ and all $y \in B : y \in B \setminus A$. We know $x$ and $y$ are then in $A \cup B$ but not $A \cap B$. Thus, all elements of $(A \setminus B) \cup (B \setminus A)$ are also in $(A \cup B) \setminus (A \cap B)$.

Therefore, for all sets $A, B$ in the same universe, then $(A \setminus B) \cup (B \setminus A) = (A \cup B) \setminus (A \cap B)$.

### Proposition 5.23

<i>The set described in Theorem **5.21** is equal to $A \Delta B$.</i>

*Proof.*

Assume that $A$ and $B$ are sets. Let there be an arbitrary element $x$. Without the loss of generality, Definition **5.14**, tells us that, if $x \in A \setminus B$, then $x \in A$ but $x \not\in B$. Thus, $(A \setminus B) \cup (B \setminus A)$ can only contain elements that are in either $A$ or $B$, but not both. Then Definition **5.22** implies that $x$ is also in $A \Delta B$. Therefore, $(A \setminus B) \cup (B \setminus A) = A \Delta B$.

### Exercise 5.24 

*Prove the following equalities of sets:*

1. $\set{8a + 17b : a, b \in \mathbb{Z}} = \mathbb{Z}$

*Proof.*

By Fact **2.3**, we know $-2b \in \mathbb{Z}$. So let $a = -2b$. Now $\set{b : b \in \mathbb{Z}}$, which is $\mathbb{Z}$. Therefore, $\set{8a + 17b : a, b \in \mathbb{Z}} = \mathbb{Z}$.

$\blacksquare$

2. $\set{12n + 9m : n, m \in \mathbb{Z}} = \set{3k : k \in \mathbb{Z}}$

*Proof.*

By Fact **2.3**, we know $-k \in \mathbb{Z}$. So let $n = k$ and $m = -k$. Now $\set{12n + 9m : n, m \in \mathbb{Z}} = \set{3k : k \in \mathbb{Z}}$. Therefore, the original statement is true.

$\blacksquare$

3. $\set{5j + 1 : j \in \mathbb{Z}} = \set{5j + 6 : j \in \mathbb{Z}}$

By Fact **2.3**, we know $z + 1 \in \mathbb{Z}$ for some $z \in \mathbb{Z}$. Now, we show $\set{5(z + 1) + 1 : z \in \mathbb{Z}} = \set{5j + 6 : j \in \mathbb{Z}}$. Therefore, the original statement is true. 

$\blacksquare$
