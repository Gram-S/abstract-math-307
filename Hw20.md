*Proof.*

<i>Let $A$ and $B$ be the sets in the same universe $U$. Then $(A \setminus B) \cup (B \setminus A) = (A \cup B) \setminus (A \cap B)$</i>.

Assume $A$ and $B$ are sets. Now, without the loss of generality, there are two cases depending if $A = B$.

**Case 1.** Assume $A = B$. Then we know the following.

$A \setminus B = \emptyset$

$B \setminus A = \emptyset$

$A \cup B = B$

$A \cap B = B$.

Now we know $\emptyset = B \setminus B$. Thus our original statement holds when $A = B$.

**Case 2.** Assume $A \not= B$. Observe that $A \setminus B$ and $B \setminus A$ can only both be the $\emptyset$ in the above case. So, without the loss of generality, we know for all $x \in A \setminus B$, then $x \in A$ and $x \not\in B$. Thus, $x$ is in $A \cup B$ but not $A \cap B$. Then by Proposition **5.20**, we know $x \in (A \cup B) \setminus (A \cap B)$. So $(A \setminus B) \cup (B \setminus A)$ and $(A \cup B) \setminus (A \cap B)$ contain the same elements. Therefore Definition **5.19** implies they are equal. 

Since the original statement holds for all sets $A, B$ with the same universe, $(A \setminus B) \cup (B \setminus A) = (A \cup B) \setminus (A \cap B)$.

$\blacksquare$

### Proposition 5.23

<i>The set described in Theorem **5.21** is equal to $A \Delta B$.</i>

*Proof.*

Assume that $A$ and $B$ are sets. Without the loss of generality, Definition **5.14**, tells us that, if $x \in A \setminus B$, then $x \in A$ but $x \not\in B$. Thus, $(A \setminus B) \cup (B \setminus A)$ can only contain elements that are in either $A$ or $B$, but not both. Then Definition **5.22** implies that $x$ is also in $A \Delta B$. Therefore, $(A \setminus B) \cup (B \setminus A) = A \Delta B$.

### Exercise 5.24 

*Prove the following equalities of sets:*

1. $\set{8a + 17b : a, b \in \mathbb{Z}} = \mathbb{Z}$.

*Proof.*

$(\subseteq)$ Denote $A = \set{8a + 17b : a, b \in \mathbb{Z}}$. We know $A$ is a subset of $\mathbb{Z}$ because Fact **2.3** implies $A$ only contains integers. Subsequently, we know $\mathbb{Z}$ is a subset of $A$ because of the following.

$(\supseteq)$ Let $-2b$ be an integer. Then, $A$ has a subset $\set{8(-2b) + 17b : a, b \in \mathbb{Z}}$, which is $\mathbb{Z}$. Thus, $\mathbb{Z}$ is a subset of $A$. 

Now $A \subseteq \mathbb{Z}$ and $\mathbb{Z} \subseteq A$. Thus, by Definition **5.19**, then $\set{8a + 17b : a, b \in \mathbb{Z}} = \mathbb{Z}$.

$\blacksquare$

2. $\set{12n + 9m : n, m \in \mathbb{Z}} = \set{3k : k \in \mathbb{Z}}$.

*Proof.*

Denote $A = \set{12n + 9m : n, m \in \mathbb{Z}}$ and $B = \set{3k : k \in \mathbb{Z}}$.

$(\subseteq)$ By Fact **2.3**, we let $4x + 3y$ be an integer for some integers $x, y$. Now $B$ has a subset $\set{3(4x + 3y) : x, y \in \mathbb{Z}}$. Notice that such a subset is the same as $A$. Thus, $A \subseteq B$.

$(\supseteq)$ Let $-n$ be an integer for some integer $n$. Now $A$ has a subset $\set{3n : n \in \mathbb{Z}}$. Notice that such a subset is the same as $B$. Thus, $B \subseteq A$.

Now $A \subseteq B$ and $B \subseteq A$. Therefore, by Definition **5.19**, then $\set{12n + 9m : n, m \in \mathbb{Z}} = \set{3k : k \in \mathbb{Z}}$.

$\blacksquare$

3. $\set{5j + 1 : j \in \mathbb{Z}} = \set{5j + 6 : j \in \mathbb{Z}}$.

Denote $A = \set{5j + 1 : j \in \mathbb{Z}}$ and $B = \set{5j + 6 : j \in \mathbb{Z}}$.

$(\supseteq)$ By Fact **2.3**, we let $x + 1$ be an integer for some integer $x$. Now $A$ has a subset $\set{5(x + 1) + 1 : x \in \mathbb{Z}}$. Notice that such a subset is the same as $B$. Thus, $B \subseteq A$.

$(\subseteq)$ We let $y - 1$ be an integer for some integer $y$. Now $B$ has a subset $\set{5(y - 1) + 6 : y \in \mathbb{Z}}$. Notice that such a subset is the same as $A$. Thus, $A \subseteq B$. 

Now $A \subseteq B$ and $B \subseteq A$. Therefore, by Definition **5.19**, then $\set{5j + 1 : j \in \mathbb{Z}} = \set{5j + 6 : j \in \mathbb{Z}}$.

$\blacksquare$
