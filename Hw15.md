### Exercise 4.4

<i>"Consider the sentence $'F(x, y) := x = y^2'$. Discuss the meaning of each of the following sentences. Which of them are true? Make sure you justify your answer."</i>

<i>"There exists $x \in \mathbb{R}$ such that there exists $y \in \mathbb{R} : F(x, y)$."</i>

**True**.

There is at least $1$ real number $x$ where $x = y^2$ for at least $1$ real number $y$.  

<i>"There exists $y \in \mathbb{R}$ such that there exists $x \in \mathbb{R} : F(x, y)$."</i>

**True**.

There is at least $1$ real number $y$, where $y^2$ is a real number. 

<i>"For all $y \in \mathbb{R}$, for all $x \in \mathbb{R}, F(x, y)$."</i>

**False**.

Every real number $y$ when squared produces every real number $x$.

### Exercise 4.5

<i>"Consider the statement “For all $\epsilon \gt 0$, there exists $N \in \mathbb{N}$ such that $\frac{1}{N} \lt \epsilon$.”
Assume the universe of possible values for $\epsilon$ is the set $\mathbb{R}$."</i> <!-- Original claim -->

<i>Express the statement in logical symbols. Is the statement true?</i>

$\forall \epsilon \gt 0 \exists N \in \mathbb{N} : \frac{1}{N} \lt \epsilon$.

<i>Can you rewrite the statement as an implication?</i>

If $\epsilon \gt 0$, then for all $\epsilon$, there exists a $N \in \mathbb{N} : \frac{1}{N} \lt \epsilon$.

<i>Reverse the order of the quantifiers to get a new statement. Does the meaning change? If
so, how? Is the new statement true?</i>

If $\exists \epsilon \gt 0$, then $\forall N \in \mathbb{N} : \frac{1}{N} \lt \epsilon$.

The conditions have a false relation when $\epsilon = 1, N = 1$. However, we only look for one value of $\epsilon$ where the statement is true. Since the term $\frac{1}{N} \leq 1$, then $\epsilon = 2$ makes the statement true.

### Exercise 4.6

<i>"Suppose that the universe of discourse is the set of real numbers. Consider the sentence $'G(x, y) := x \gt y'$. Find all possible distinct ways to quantify the variables to create propositions and then determine the truth value of each.".</i> <!-- Original claim -->

There are $4$ cases. 

$\forall x \gt \forall y$.

States that all real numbers are greater than all real numbers. False.

$\forall x \gt \exists y$.

States that there is a real number $y$ such that all real numbers are greater than it. False because it also implies that $y \gt y$. 

$\exists x \gt \forall y$.

States that there is a real number $x$ such that all real numbers are less than it. False because it also implies that $x \lt x$.

$\exists x \gt \exists y$.

There exists a real number and there exists a real number large than it. $3 \gt 2$. True.

### Exercise 4.7

<i>"Convert the following statements into statements using only logical symbols."</i> <!-- Original claim -->

<i>"There exists a real number $x$ such that $x^2 + 1$ is greater than zero."</i>

$\exists x : x^2 + 1 \gt 0$.

<i>"There exists a natural number $n$ such that $n^2 = 36.$"</i>

$\exists n : n^2 = 36$.

<i>"For every real number $x, x^2$ is greater than or equal to zero."</i>

$\forall x \in \mathbb{R} \implies x^2 \geq 0$.

### Exercise 4.8 

<i>"Express the statement 'For all $x, y \in \mathbb{R}$ such that $x \lt y$, there exists $m \in \mathbb{R}$ such
that $x \lt m \lt y$' using logical symbols."</i> <!-- Original claim -->

$\forall (x, y) \in \mathbb{R} : x \lt y \implies \exists m \in \mathbb{R} : x \lt m \lt y$.
