*def 1.* Denote the set of integers: $\Z = \{..., -2, -1, 0, 1, 2, ...\}$.

*def 2.* An integer $n$ is odd if $n = 2k + 1 : k \in \Z$

*def 3.* An integer $n$ is even if $n = 2k : k \in \Z$.

**Claim**: The sum of an odd integer $o$ and even integer $e$ is odd.

*axiom 1.* Sums and Products of integers are integers.

Assume that $o$ is an odd integer and $e$ is an even integer.

Denote $i$ as some integer.

Note that, by *axiom 1*, $4k$ is also an integer because $4$ and $k$ are integers.

Therefore, $i = 2k$

We know $o + e = 2k + 2k + 1$ using *def 2* and *def 3*.

Then, $o + e = 4k + 1 = 2(2k) + 1$

But we can substitute $2k$ for $i$, so $o + e = 2i + 1$.

Recall that, by the definition of an odd number, $k$ is an arbitrary integer. Since $i$ is also an arbitrary integer, it can be used in the definition.

So, $o + e$ is an odd integer.
