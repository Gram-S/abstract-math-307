Theorem 2.4 is nonessential in the proof depicted in problem 2.6.

Problem 2.6, if treated as an axiom, can be used to prove theorem 2.4: 

*def 1.* Denote the set of integers: $\Z = \{..., -2, -1, 0, 1, 2, ...\}$.

*def 2.* An integer $e$ is even if $e = 2k : k \in \Z$

*axiom 1* The sum of an even and an odd integer is odd.

**Claim:** If $n$ is an integer, then $n + n + 1$ must be odd.

Assume that $n$ is an integer.

Then, $n + n + 1 = 2n + 1$

Since $n$ is an integer and thus $n \in \Z$, we let $k = n$.

So, using *def 2* $2n + 1 = 2k + 1 = e + 1$

Note $1 = 2(0) + 1$, therefore, $1$ is an odd integer.

By definition, $e$ is an even integer.

By *axiom 1*, $e + 1$, the sum of an odd and even integer, is odd.

Therefore, $n + n + 1$ is odd. 

We can compare proofs based on the principle of parsimony, that is, if one proof is simpler than the other, it is a better solution. However, both proves require the same amount of definitions and are relatively the same size and complexity, so I don't think one is strictly better than the other.
