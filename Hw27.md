# Problem 6.14

A special chessboard is $2$ squares wide and n squares long. Using $n$ blank
dominoes that are $1$ square by $2$ squares, there are many ways to perfectly cover this chessboard
with no overlap. How many? Prove your answer.

*Proof.*

We proceed by induction, so there are two cases. 

*(i).* Consider when $n = 1$. Since the chessboard is the same size as a dominoe, we can only place $1$ dominoe on the board in $1$ orientation. Therefore, there is only $1$ way to place dominoes on a $2 \times n$ chessboard.

*(ii).* Assume that there exists an arbitrary $n \in \mathbb{N}$ such that $f(n) = f(n-1) + n - 1$ is the number of ways to perfectly cover any $2 \times n$ chessboard.
