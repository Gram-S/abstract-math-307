# Problem 6.14

A special chessboard is $2$ squares wide and n squares long. Using $n$ blank
dominoes that are $1$ square by $2$ squares, there are many ways to perfectly cover this chessboard
with no overlap. How many? Prove your answer.

Claim: For all $n \in \mathbb{N}$, for any $2 \times n$ chessboard, the number of ways to perfectly cover it is given by 

$$
f(n) =
\begin{cases}
f(n-1) + f(n-2) & \text{ if } n \geq 2 \\
1 & \text{ if } n = 1 \\
2 & \text{ if } n = 2.
\end{cases}
$$

*Proof.*

We proceed by induction, so there are two cases.

*(i).* Consider a $2 \times 1$ chessboard. We can only fit one dominoe, so there is only $1$ way to cover it. So $f(1) = 1.$ Now consider a $2 \times 2$ chessboard. We can either align $2$ dominoes veritcally or horizontally. So there are two ways to cover it. So $f(2) = 2$. Thus, our original claim holds for $2 \times 1$ and $2 \times 2$ chessboards.

*(ii).* Assume there exists some arbitrary $n \in \mathbb{N}$ such that the number of ways to cover $2 \times n$ is $f(n)$ and $2 \times n - 1$ is $f(n-1)$.

Note that for any dominoe on the board, it is either horizontal (taking up a full row), or vertical (in two rows). If it is vertical, then it must be perfectly alligned with another vertical dominoe. Otherwise, there is a $1 \times 1$ gap which cannot be filled without creating another gap are two possible ways to cover it. Now consider a $2 \times n + 1$ chessboard. Any arbitrary perfect covering is then in either one of two sets.

1. Consider a set of every covering where the $n+1^{st}$ row is perfectly covered by a horiontal dominoe. Now, by our inductive hypothesis, there are $f(n)$ ways to fill the other $n$ rows. Thus, there are $f(n)$ elements in this set.

2. Consider a set of every covering where the $n+1^{st}$ and $n^{th}$ rows are perfectly covered by two vertical dominoes. Now, by our inductive hypothesis, there are $f(n-1)$ ways to fill the other $n-1$ rows. Thus, there are $f(n-1)$ elements in this set.

Note that these two cases are pairwise disjoint, as the $n+1^{st}$ row cannot be occupied by a horizontal dominoe, if and only if, the $n+1^{st}$ and $n^{th}$ rows are perfectly covered by two vertical dominoes. Thus, the sum of elements in both sets is the total number of perfect coverings. Therefore, the number of perfect coverings for a $2 \times n+1$ chessboard is $f(n) + f(n-1)$.

So, by the PMI, the number of ways to cover a $2 \times n+1$ chessboard is given by 

$$
f(n) =
\begin{cases}
f(n-1) + f(n-2) & \text{ if } n \geq 2 \\
1 & \text{ if } n = 1 \\
2 & \text{ if } n = 2.
\end{cases}
$$


$\blacksquare$

# Problem 6.14

*Proof.*

We proceed by induction, so there are two cases.

*(i).* Consider a $2 \times 2$ board. Observe that if any tile is empty, we can fill the remaining tiles with $1$ piece. Thus, our original statement holds when $n = 1$.

*(ii).* Assume there exists some $n \in \mathbb{N}$ such that we can perfectly cover every $2^n \times 2^n$ board with an empty square. Now consider a $2^{n+1} \times 2^{n+1}$ board, with some square removed, called $B$. Then $B$ has a length and width of $2^n(2^n)$. Thus, we can split $B$ into four $2^n \times 2^n$ quadrants. Now assume the removed square is in quadrant $B_i$. Our inductive hypothesis implies we can perfectly cover $B_i$. Now, define the middle to be the $2 \times 2$ area in the middle of $B$. Now, temporarily remove every square in the middle that doesn't belong to $B_i$. By our inductive hypothesis, there is a way to cover every quadrant except for the $3$ squares in the middle. But we can always cover those $3$ squares with an L-shaped piece. Thus, we can always cover every quandrant. Therefore, we can cover $B$. 

Thus, by the PMI, we can cover every $2^n \times 2^n$ board.

$\blacksquare$
