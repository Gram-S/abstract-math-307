# Problem 6.14

A special chessboard is $2$ squares wide and n squares long. Using $n$ blank
dominoes that are $1$ square by $2$ squares, there are many ways to perfectly cover this chessboard
with no overlap. How many? Prove your answer.

Claim: For an $2 \times n$ size chessboard, the number of ways to perfectly cover it is given by $f(1) = 1, f(n) = f(n-1) + n - 1$.

*Proof.*

We proceed by induction, so there are two cases. 

*(i).* Consider when $n = 1$. Since the chessboard is the same size as a dominoe, we can only place $1$ dominoe on the board in $1$ orientation. Therefore, there is only $1$ way to place dominoes on a $2 \times n$ chessboard.

*(ii).* Assume that there exists an arbitrary $n \in \mathbb{N}$ such that $f(n) = f(n-1) + f(n-2)$ is the number of ways to perfectly cover any $2 \times n$ chessboard. Now consider a chessboard of length $2 \times n+1$ with $f(n+1)$ ways to perfectly cover it. Now, parition the ways to fill the chessboard into the following sets. 

1. A set containing every cover where the $0$ through $n^{th}$ rows are a perfect cover for a $2 \times n$ chessboard and the $n+1^{st}$ row is a horizontal dominoe. Since there are $f(n)$ perfect covers for a $2 \times n$ chessboard, this set contains $f(n)$ elements.

2. A set containing every cover where the $0$ through $n-1^{th}$ rows are a perfect cover for a $2 \times n-1$ chessboard and the $n$, $n+1^{st}$ rows are two vertically alligned dominoes. Since there are $n-1$ ways  to cover a $2 \times n-1$ chessboard, this set contains $f(n-1)$ elements.

The total number of ways to cover the chessboard are the sum of these sets. So $f(n+1) = f(n) + f(n-1)$. 

$\blacksquare$
