# Problem 6.14

A special chessboard is $2$ squares wide and n squares long. Using $n$ blank
dominoes that are $1$ square by $2$ squares, there are many ways to perfectly cover this chessboard
with no overlap. How many? Prove your answer.

Claim: For all $n \in \mathbb{N}$, for any $2 \times n$ chessboard, the number of ways to perfectly cover it is given by 

$$
f(n) =
\begin{cases}
f(n-1) + f(n-2) & \text{ if } n \geq 2 \\
1 & \text{ if } n = 1 \\
2 & \text{ if } n = 2.
\end{cases}
$$

*Proof.*

We proceed by induction, so there are two cases.

*(i).* Consider a $2 \times 1$ chessboard. We can only fit one dominoe, so there is only $1$ way to cover it. So $f(1) = 1.$ Now consider a $2 \times 2$ chessboard. We can either align $2$ dominoes veritcally or horizontally. So there are two ways to cover it. So $f(2) = 2$. Thus, our original claim holds for $2 \times 1$ and $2 \times 2$ chessboards.

*(ii).* Assume there exists some arbitrary $n \in \mathbb{N}$ such that for a $2 \times n$ chessboard, there are $f(n)$ ways to cover it. Now consider a $2 \times n + 1$ chessboard. We split possible coverings into two cases.

First, every possible covering where the $n+1^{st}$ row is a horizontal dominoe. Now, by our inductive hypothesis, the way to fill the empty items in the chessboard is $f(n).$ Thus, there are $f(n)$ ways to fill a $2 \times n+1$ chessboard with a horizontal dominoe in the first row.

Second, every possible covering where the $n^{th}$ and $n+1^{th}$ row contain two vertically alligned domineos. Now, the number of ways to fill the remaining $n-1$ rows is $f(n-1).$

Thus, the number of ways to cover a $2 \times n+1$ chessboard is $f(n) + f(n-1).$ Which we know is equal to $f(n+1)$. 

$\blacksquare$
