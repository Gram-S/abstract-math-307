$\blacksquare$

### Theorem 4.15

<i>"Let $U$ be the universe of discourse. Suppose that for each $x \in U$ we have a statement $P(x)$, which might be true or false depending on $x$. Then:"</i> 


**a.** We know $\lnot((\forall x \in U)P(x))$ is equivalent to $(\exists x \in U)(\lnot P(x))$.

*Proof.*

$\implies$ If it is not true that $(\forall x \in U)(P(x))$ is true, then there exists at least one $x$ which makes $P(x)$ false. 

$\impliedby$ If there exists one $x$ which makes $P(x)$ false, then $\forall x$, we know $P(x)$ is not true. 

Thus, the two statements imply each other. Therefore, the original statement is true. 

$\blacksquare$

**b.** We know $\lnot (( \exists x \in U ) P(x) )$ is equivalent to $(\forall x \in U)(\lnot P(x))$.

$\implies$ Assume there exists no $x$ such that $P(x)$ is true. Then for $\forall x$, we know $P(x)$ is never true. 

$\impliedby$ Assume $\forall x$, then $P(x)$ is always false. Then there exists no $x$ which makes $P(x)$ true.

Thus, the two statements imply each other. Therefore, the original statement is true. 

$\blacksquare$

### Exercise 4.16

<i>"For each of the following, use **Theorem 4.15** to give a negation which begins with the opposite quantifier. Disregard the truth value of any particular statement."</i> 

**a.** $(\forall x)(x > 3)$.

$$\lnot((\exists x)(x > 3)).$$

**b.** $(\exists x)(x is prime and x is even)$.

$$\lnot((\forall x)(x is not prime and x is not even)).$$

**c.** $Every wookie is named Chewbacca.$

$$There exists no wookie not named Chewbacca.$$

**d.** $Some hippies are Republican.$

$$All hippies are not non-Republican.$$

**e.** $There exists x \in \mathbb{Z} such that 1/x \notin \mathbb{Z}$.

$$For all x \in \mathbb{Z}, then 1/x \in \mathbb{Z}.$$

**f.** $There is no function f such that if f is continuous, then f is not differentiable.$

$$For all f that is continuous, then f is differentiable.$$
